# (オンライン、1Week) Claude Code で学ぶ実践開発

Web アプリを実装するためのテンプレートリポジトリです。

実装する内容の理解を深めるための講義資料の一部も含まれています。

## テンプレートリポジトリの利用方法

GitHub のテンプレートから、自分のリポジトリを作成して使用します。

1. GitHub の画面で右上にある `Use this template` を選択する
2. `Create a new repository` を選択する
3. Owner
   が自分の名前になっていることを確認し、好きなリポジトリ名を入力して、リポジトリを作成する
4. 作成した自分のリポジトリを VS Code でクローンする

## 起動方法

### Node.js のインストール

https://nodejs.org/ja から Node.js をインストールしてください。
（分かる方は好きな方法でインストールしてもらって大丈夫です。）

Node.js は 20.19 以上、または 22.12 以上のバージョンを使用してください。

### 依存関係のインストール

初回のみ、依存関係をインストールします。

```sh
npm install
```

### 開発サーバー起動

```sh
npm run start
```

起動後、通常は http://localhost:5173/ をブラウザで開いてください。
5173 ポートがすでに使われている場合は、ターミナルに表示された URL を開いてください。

## 実装する場所

HTML、CSS、JavaScript、画像などのファイルは `public/`
フォルダ内に追加・変更してください。

`public/`
の内容を変更したら、ブラウザを再読み込みすると変更内容を確認できます。サーバーの再起動は必要ありません。
